HOW TO RUN THE FRONTEND
=======================

1. Install dependencies (first time only):
   npm install

2. Start the dev server:
   npm run dev

3. Open in browser:
   http://localhost:5173

That's it. No backend, no API — everything is static files.

---

WHAT'S IN THE REPO
==================

src/app/components/
  Layer1–5.tsx   — the five explorable sections
  ToolCard.tsx   — shared components (Lightbox, PredictionReveal, Section, etc.)

public/images/
  cultural/      — 9 real SD 2.1 images (wedding/breakfast/funeral × default/Nigeria/Japan)
  swaps/         — 15 prompt-swap images (3 pairs × 5 denoising steps, seed_00)

All data (DINOv2 distances, aesthetics scores, lock-in curves) is embedded
directly as TypeScript constants — no JSON files need to be present.

---

NODE VERSION
============

Tested on Node 18+. If npm install fails, check your node version:
  node --version

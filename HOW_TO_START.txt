HOW TO RUN
==========

1. Install dependencies (first time only):
   npm install

2. Start the dev server:
   npm run dev

3. Open in browser:
   http://localhost:5184

No backend, no API. Everything is static files.


BEFORE YOU PUSH
===============

Run BOTH. `vite build` is transpile-only and will happily succeed on an
undefined-variable reference; `tsc` is what catches it. That exact bug once
shipped a blank white page despite a clean build.

   npm run typecheck
   npm run build


WHAT'S IN THE REPO
==================

src/sections/     the numbered scenes, in page order
src/components/   Scene shell, the chart primitives (Viz.tsx), the model switcher
src/data/         every number the page shows, exported from the analysis pipeline
public/images/    9,236 generated images, attention maps and reference photographs

The data and images are produced by
code_giray/scripts/phase4_frontend_export/ in the research repo. They are
committed here so the site builds with no pipeline present.


DEPLOYMENT
==========

Pushing to main triggers a Cloudflare build, which runs `npm install` and
`npm run build`, then serves ./dist at promptswontsaveyou.dev.
See wrangler.jsonc. `dist/` and `node_modules/` are intentionally NOT tracked.
